## Ejercicio 3: Implementación del Analizador Léxico

### Instrucciones:

Ahora deben **implementar en código** el ejercicio 1.

- El objetivo es crear un analizador léxico que procese un fragmento de código fuente, identifique los **tokens**, y los clasifique por tipo.
- El programa debe indicar la **línea y columna** de aparición de cada token.
- Puede implementarse en el lenguaje de tu preferencia (sugerencia: Python, Java o JavaScript).
- El resultado debe ser una **tabla o estructura de datos** que muestre los campos: `Token`, `Tipo`, `Línea`, `Columna`.

**Tips para ayudarte:**
- Usá expresiones regulares para reconocer los patrones.
- Iterá línea por línea y carácter por carácter si es necesario.
- Podés tomar como base el ejemplo resuelto en el Ejercicio 1.
